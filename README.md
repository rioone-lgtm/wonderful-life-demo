# 犬の保育園「わんだふるライフ」リニューアル 制作サンプル

千葉県佐倉市の犬の保育園「わんだふるライフ」（https://wonderful-life-dog.com/ ）のホームページ全体リニューアル案件に応募するための**制作サンプル**です。公式サイトではありません。検索エンジンには載せない設定（`noindex`）にしています。

- **URL の末尾に `?notes` を付けると制作メモが出ます**（例: `https://…vercel.app/?notes`）。各セクションに「元サイトからどう変えたか・なぜそうしたか」の説明が付き、画面上部に「制作メモを隠す／表示」の切り替えボタンも出ます。
  `?notes` で開いているあいだは、サイト内のリンクにも `?notes` を引き継ぎます。`?notes` の無い URL ではボタンもメモも出ません（状態は記憶しません）。
- 写真・ロゴ・文章は現行サイトのものを使用。未確定の内容には「仮」「確認中」「ご提供後に差し替え」と表示しています。
- フォームは送信しません（入力内容はどこにも送信・保存されず、送信完了画面へ移動するだけです）。

## ページ構成

| URL | ページ | 内容 |
|---|---|---|
| `/` | トップ | ご指定の順（キャッチ・写真・申込ボタン・YouTube → 保育園／お家で学ぶ → LINE プレゼント → 初めての方へ → 施設紹介 → Instagram → 体験入園の流れ → FAQ → 大きな申込ボタン）＋お知らせ |
| `/first` | 初めての方へ | 保育園の考え方・社会化を大切にする理由・利用の始め方 |
| `/nursery` | 犬の保育園 | サービスの特徴・学べること・保育園の1日 |
| `/facility` | 施設紹介 | 室内・スタッフ・外観・所在地・駐車場 |
| `/trial` | 体験入園 | 流れ・料金・利用条件・よくある質問・申込フォーム |
| `/thanks` | 送信完了 | フォーム送信後の画面 |
| `/blog` | ブログ一覧 | 一覧の共通デザイン |
| `/blog-post` | ブログ記事 | 記事を開いた画面の共通デザイン |

上部メニューはご指定の順（初めての方へ／犬の保育園／お家で学ぶ／YouTube／施設紹介／ブログ／体験入園を申し込む）。「お家で学ぶ」の教材ページと公式 LINE の友だち追加 URL、トップに埋め込む YouTube 動画は未指定のため、押すと「URL はご指定後に設定」と表示します。

## ファイル構成・ビルド

- `src/layout.html` … 全ページ共通のヘッダー・フッター
- `src/pages/*.html` … 各ページの中身（先頭の `<!--{...}-->` にタイトルなど）
- `node tools/build.mjs` … 上の2つを組み合わせて、ルートに `*.html` を書き出す（依存パッケージなし）
- `assets/` … CSS / JS / 画像（現行サイトの画像を WebP に変換）

ルートの `*.html` はビルド結果ですが、Vercel ではビルドせずにそのまま配信するため、コミットしてあります。`src/` を直したら `node tools/build.mjs` を実行してください。

## 技術メモ

- 素の HTML / CSS / JavaScript（フレームワーク・ビルド依存なし）
- モバイルファースト（ブレークポイント 640px / 960px / 1100px）、横スクロールなし、操作要素は 44〜52px 以上
- JavaScript が動かなくても全内容を読める作り（開閉式 FAQ は `details` 要素）
- `prefers-reduced-motion` で動きを止める
- 実装時は現行の WordPress（SWELL テーマ）上に、固定ページ＋ブロックで再構成し、文章・写真・料金を管理画面から変更できる形にする想定
